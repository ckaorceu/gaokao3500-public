# 高考英语 3500 词 · 巧记

一个零后端、纯前端的单词记忆网站，基于艾宾浩斯遗忘曲线做间隔重复复习，覆盖高考核心词汇。

> 在线访问：**https://word.tutw.fun**

---

## 功能特性

### 五种练习模式（进入单词前在首页选择）
1. **看词记义** — 看单词 + 音标，点击「显示释义」后再评级（不会 / 模糊 / 一般 / 熟记）
2. **看义记词** — 只给中文释义，输入框写出英文，即时核对 ✅/❌
3. **听音拼写** — 自动朗读单词（无文字），凭听写拼写核对
4. **看英选中** — 显示英文，从 4 个中文释义里选正确答案
5. **看中选英** — 显示中文释义，从 4 个英文单词里选正确答案

### 科学的复习机制
- **间隔重复（Spaced Repetition）**：每个词按掌握等级排程下次复习时间 —— 不会=当天、模糊=1 天后、一般=3 天后、熟记=7 天后；到点优先复习。
- **分模式进度**：每种练习模式独立计算掌握度与待复习量，互不干扰。
- **薄弱词速攻**：「只练未掌握」开关，只刷评级 0/1 的词。
- **重复记忆**：打开后，本轮评「不会/模糊」的词自动重排到队尾再练，直到评到「一般/熟记」或达到上限（上限可选 1/2/3/5/∞）。

### 巧记方法（用户自定义）
每个词可填 4 类独立巧记，学习页底部「💡 巧记方法」面板分条展示：
- 🧠 联想记忆 · 🌱 词根词缀 · 🔊 谐音记忆 · 📖 例句

### 其他
- 🔊 单词朗读（浏览器内置 `speechSynthesis`，无需联网 TTS）
- 美 / 英音标分显（`美 /.../ 英 /.../`）
- A–Z 字母索引（含「全部」）+ 实时搜索 + 按复习等级筛选
- 单词顺序 / 乱序 切换
- 进度全部存于浏览器 `localStorage`，刷新不丢

## 本地运行

纯静态站点，无需构建、无需安装依赖。任选一种：

```bash
# 方式一：Python 自带服务器（推荐，已处理 UTF-8 编码）
python serve.py
# 打开 http://127.0.0.1:8765

# 方式二：任意静态服务器
python -m http.server 8765
# 或 npx serve .
```

> ⚠️ 直接双击 `index.html` 用 `file://` 打开也能跑，但部分浏览器对 `localStorage`/`speechSynthesis` 有限制，建议用本地服务器。

## 数据来源

词库来自开源项目 [RealKai42/qwerty-learner](https://github.com/RealKai42/qwerty-learner) 的 `GaoKao_3500.json`，共 **3893 条**高考词汇，每条含：

- 单词、美式音标（`usphone`）、英式音标（`ukphone`）
- 多个中文释义（`trans`）

> 注：常见 PDF 版「3500 词」实际仅约 1700 条（多词性合并），本项目采用质量更高的开源词库，词量更全。

## 复习算法说明

每个词在每种模式下维护一个记录：`{ l, due, iv }`
- `l`：掌握等级（0 未学 / 1 不会 / 2 模糊 / 3 一般 / 4 熟记 的离散映射）
- `due`：下次复习到期时间戳
- `iv`：当前复习间隔（天）

评级触发排程（天数）：

| 评级 | 含义 | 下次复习 |
|------|------|----------|
| 不会 (0) | 完全不认识 | 当天重练 |
| 模糊 (1) | 有点印象 | 1 天后 |
| 一般 (3) | 基本会 | 3 天后 |
| 熟记 (5) | 扎实掌握 | 7 天后 |

队列排序：**到期优先**（更早到期的先练）→ 同到期按等级升序（未学/低级优先）→ 未到期的按临近到期先。开启「乱序」则整体 Fisher–Yates 打乱。

## 部署（Vercel + GitHub 自动部署）

- 仓库：https://github.com/ckaorceu/gaokao3500
- 推送到 `main` 分支即自动触发 Vercel 生产部署，无需手动命令。
- 手动部署（备用）：`npx vercel deploy --prod --yes --scope ckaorceus-projects`

## 浏览器兼容性

现代 Chromium / Edge / Firefox / Safari 均可。朗读功能依赖浏览器 `speechSynthesis`，个别旧版浏览器可能不支持英文语音，此时朗读按钮无声音但不影响其他功能。
